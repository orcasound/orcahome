# How to update orcasound.tech

You can change the words and pictures on orcasound.tech yourself, in a website
called **Sanity Studio**. There's no code involved, and your changes show up on
the site about a minute after you publish them.

## Getting started

1. Go to **https://orcahome.sanity.studio**
2. Sign in with your Google account. If it says you don't have access, ask
   Vicky on Zulip to add you.
3. On the left you'll see a list of everything you can change. Click one to
   open it.

![The Studio, with the list of things you can change on the left](/editor-guide/images/projects/01-studio-sidebar.png)

## Four things to remember

1. **Click Publish.** Nothing changes on the website until you click the green
   **Publish** button at the bottom. If you see "Unpublished changes", your
   edits aren't on the website yet.
2. **Wait about a minute, then refresh.** Use Cmd + Shift + R (Mac) or
   Ctrl + Shift + R (Windows) so you see the newest version.
3. **Don't change the web address of a page that's already published.** On
   blog posts and projects this is the box called **Slug**. Changing it breaks
   every link to that page.
4. **An empty box is safe.** On the main pages, if you leave a box empty, the
   website shows its usual text or picture instead.
