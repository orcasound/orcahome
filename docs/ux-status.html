Orcahome UX: Onboard, Browse, Request

One place to get set up, browse open UX work on Orcahome (the Orcasound Product Team's proof-of-concept site at orcasound.tech), read each brief, and request a project. Owners and titles are read live from GitHub; status reflects a manual audit by the Product Manager. Requests email the Product Manager; assignment stays the Product Manager's call (no self-assign).

Get set up

1

Join Zulip

Our team chat. Join the Orcasound Zulip, then say hi in the UX Team channel.

2

Get on GitHub

Create a GitHub account if you need one, then explore the Orcasound org. You will be added to the orcahome repo once you claim a project.

3

See the Design System

Our working Design System (Figma) is the visual reference. It is evolving as the Design System Lead comes on board.

4

Pick, read, request

Browse the open issues below, open the brief that fits you, then use the Request button. The Product Manager reviews and assigns.
