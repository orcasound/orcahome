Orcahome Dev: Onboard & Track

One place for developers to get set up and see who is on what across Orcahome dev work (the Orcasound Product Team's proof-of-concept site at orcasound.tech). Titles and last activity are read live from GitHub; owners and status reflect the Product Manager's Sprint 3 audit. New devs: get set up below, then message Vicky Li (dev lead) on Zulip for an assignment.

Get set up

1

Join Zulip

Our team chat. Join the Orcasound Zulip, then say hi in the orcahome channel.

2

Get on GitHub

Create a GitHub account if you need one and share your handle. Vicky adds you to the orcasound/orcahome repo.

3

Clone & run locally

Clone the repo and follow the README to get the site running. Ask in the orcahome channel if you hit setup snags.

4

Get your assignment

Message Vicky Li (dev lead) on Zulip. She triages and assigns issues. Browse open work below first so you can flag what interests you.
